Demonstration of SIGHUP dynamic config reload:
1. Boot server with initial config (port 49152, log_level info).
2. Modify config file: change log_level to debug, change port to 49153.
3. Send SIGHUP: server live-applies debug log_level and logs warning that host/port change requires restart.
4. Modify config file with invalid JSON syntax.
5. Send SIGHUP: server catches error, logs descriptive error, and retains existing valid configuration without crashing.
